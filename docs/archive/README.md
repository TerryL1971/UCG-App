# Archive

Documents that describe earlier versions of the UCG app. Kept for history,
**not** a description of the app today. For how the app works now, see
[`../companion-app.md`](../companion-app.md).

- Before Nov 2026 the app was planned around the UCG website's inventory,
  a DealerTeam/Salesforce API, an AI assistant, in-app PayPal deposits,
  and (briefly) staff logging into the app with a private in-app chat.
- All of that was dropped: the app is now customer-only, starts after the
  $300 deposit, and UCG talks to customers on WhatsApp.
- The original app's code is preserved in the private GitHub repo
  `TerryL1971/UCG-App-original`, and tagged `original-before-pivot` here.
